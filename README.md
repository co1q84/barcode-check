# 条码核验

项目名为 `barcode-check`，使用 Python 和 Tkinter。作业员先设置本批次的核验目标，再连续扫码，现场确认物料编码、厂家和数量。现场约束见 [PRODUCT.md](PRODUCT.md)。

## 启动和使用

在装有 Python 3.12 和 Tkinter 的 Windows 上，从项目目录启动。

```powershell
python -m pip install -r requirements.txt
python -m barcode_check
```

1. 首次打开「设置」，在条码基表新增记录，或导出 Excel 模板、填写后导入。可在编辑窗口用样本条码试扫。
2. 返回主窗，输入已维护的物料编码，选厂家，按需填写应扫数量，点击「开始核验」。扫码枪发送回车后自动提交，也可手工输入并按回车。按 `F2` 可从主窗返回扫码框。
3. 核验中可删除单条记录或导出记录。结束后可查看和导出本批记录。新建批次或关闭前，界面会提示导出。

基表模板和数据使用 `.xlsx`。核验记录导出使用 UTF-8 CSV，可在 Excel 中将条码和编码列按文本读取以保留前导零。「仅通过」可用于复核有效记录，「全部记录」用于查看通过项及现场异常。

使用以下命令运行测试。

```powershell
python -m unittest discover -s tests -v
```

## 打包 Windows 单文件 EXE

在装有 64 位 Python 3.12 的 Windows 上，进入源码中含有 `barcode-check.spec` 的目录，运行以下命令。

```powershell
python -m pip install -r requirements.txt "PyInstaller==6.22.3"
python -m PyInstaller --clean barcode-check.spec
```

生成的单文件程序位于 `dist/barcode-check.exe`。

## 首版界面设计

### 核验主窗口

| 位置 | 内容和操作 |
| --- | --- |
| 顶部 · 核验目标 | 输入物料编码、下拉选择厂家、填写应扫数量（可选）。点击「开始核验」后固定本批目标，保留「结束核验」和「设置」入口。 |
| 中部 · 连续扫码 | 左侧是扫码框和居中的大字结果提示，右侧是大号有效数量。有目标时显示「有效 7 / 应扫 10 · 还差 3 件」。无目标时显示「有效 7 件 · 未设应扫数量」。 |
| 下方 · 条码记录 | 「导出记录」在表格上方。表格按录入倒序，列为条码、厂家、时间、结果、说明和操作。厂家来自命中的条码规则，未识别时显示「—」。每行可删除。可选择每页 20、50 或 100 条。默认每页 20 条，表格优先预留 20 行高度，屏幕较矮时可在表内滚动。 |

沿用同级 `barcode-bridge` 的 `barcode_bridge/theme.py` 和 `barcode_bridge/ui.py` 的白底、浅灰分隔、蓝色焦点和 Microsoft YaHei UI 字体。使用常规 Windows 窗口，支持调整大小和最大化。用文字配合颜色显示状态，最近一次结果放在扫码框下方。

### 设置窗口

设置窗口只显示一个条码基表，列为「编码」「厂家」「条码前缀」。编码和厂家组合唯一，每行一个前缀。前缀完全相同会冲突，前缀重叠时选最长前缀。基表支持搜索、新增、编辑和多选批量删除。

条码基表和每页条数保存在当前 Windows 用户的 `%APPDATA%\barcode-check\settings.json`。程序首次保存时创建目录。旧版设置文件会提示格式错误，原文件会保留。

基表编辑提供「试扫」，显示命中的前缀、编码和厂家。删除前显示本次勾选数量。基表修改从下一批核验生效。

## 关键交互

- **开始与连续扫码。** 开始核验前需在设置中添加基表记录。开始核验后光标进入扫码框。每次回车提交后恢复扫码焦点，表格回到第一页并显示最新一条。导出按所选范围处理整个批次。
- **厂家提示。** 核验通过时显示识别到的厂家和本次条码。厂家不符时显示目标厂家和实际识别的厂家，两处提示均放大并加粗厂家名称。
- **异常反馈。** 重复码或结束核验时数量不足，扫码区和数量区变为琥珀色。未识别、编码或厂家不符、超量时，两区变为红色。每次扫码异常或数量不足提示播放一次 Windows 系统异常提示音，下一次扫码通过后恢复白底。超量时弹窗并暂停收码，关窗后恢复扫码焦点。
- **结束与换批。** 数量不足时点击「结束核验」，提示具体差额，可继续扫码或明确选择「结束并标记不足」。结束后的记录可查看和导出。已有录入时，换批或关闭前提示导出。
- **条码记录与导出。** 扫码和手工录入共享同批去重。核验中删除有效行后立即重算数量并允许补扫该码。导出包含实际匹配的「厂家」及批次的「目标厂家」。
- **Excel 基表。** 「导出 Excel 模板」下载空白工作簿，「导出数据」导出当前基表。导入使用一张名为「基表」的工作表，第一行依次为「编码」「厂家」「条码前缀」。数据项接受单行文本，导入时自动去掉首尾空白。编码和条码前缀也接受最多 15 位的非负整数，数字单元格可使用常规、整数 `0` 或文本格式。需要保留前导零或 16 位以上的数字时，请以文本填写。重复组合、重复前缀、空字段或格式错误会直接弹错，指出涉及的 Excel 行和原因。全表校验通过后一次性追加，失败时整批不写入。
